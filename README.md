# 🤖 Dory Reminder Bot

Telegram-бот и Mini App для создания и управления напоминаниями с поддержкой различных
типов повторов и часовых поясов.

## ✨ Возможности

- **Создание напоминаний** с различными типами повторов:
  - Сегодня/завтра
  - Ежедневно
  - По дням недели (можно выбрать несколько)
  - Раз в месяц (с выбором числа)
  - Раз в несколько дней
  - Раз в год
  - Разовое напоминание в конкретную дату

- **Управление напоминаниями**:
  - Просмотр списка активных напоминаний
  - Редактирование существующих напоминаний
  - Удаление напоминаний
  - Постановка на паузу/возобновление

- **Поддержка часовых поясов**:
  - Персональный часовой пояс для каждого чата
  - Автоматический расчёт времени с учётом перехода на летнее время

- **Два интерфейса**:
  - Команды и пошаговые мастера в чате
  - Telegram Mini App — список, форма и настройки в одном экране
  - Поддержка групповых чатов

## 🏗️ Архитектура

Проект построен по принципам **Clean Architecture**:

```
├── cmd/bot/                  # Точка входа приложения
├── internal/
│   ├── config/               # Конфигурация
│   ├── domain/               # Бизнес-модели и их валидация
│   ├── repository/           # Слой данных (SQLite) и миграции
│   ├── usecase/              # Бизнес-логика
│   ├── scheduling/           # Расчёт времени срабатывания напоминаний
│   ├── infrastructure/       # Подключение к БД
│   └── delivery/
│       ├── telegram/         # Бот: команды, мастера, планировщик рассылки
│       └── webapp/           # Mini App: HTTP API и статика
├── pkg/                      # Переиспользуемые пакеты
└── data/                     # База данных SQLite
```

Слой `internal/scheduling` намеренно вынесен из доставки: одну и ту же арифметику
времени используют мастер в чате, HTTP API и планировщик.

## 🚀 Быстрый старт

### Предварительные требования

- Go 1.26+ (нужен CGO — сборка `go-sqlite3`)
- [Task](https://taskfile.dev) для запуска команд
- Docker (опционально)

### Установка инструментов разработки

```bash
task deps:tools
```

### Настройка

1. Скопируйте `.env.example` в `.env` и заполните значения:

```env
TELEGRAM_TOKEN=your_bot_token_here
BOT_NAME=your_bot_name
ENV=dev
```

2. Получите токен бота у [@BotFather](https://t.me/BotFather) в Telegram.

Для Docker-разработки скопируйте `.env.dev.example` в `.env.dev` — этот файл
используется `docker-compose.dev.yaml`.

### Запуск в режиме разработки

```bash
task dev
```

Приложение запустится с hot-reload через Air.

### Сборка и запуск

```bash
task build:bot
./bin/bot
```

## 📱 Telegram Mini App

Mini App — это веб-интерфейс поверх того же API, что использует бот: напоминания,
созданные в приложении, видны в `/list`, и наоборот.

### Требования

Telegram открывает Mini App **только по публичному HTTPS-адресу**. Само приложение
слушает обычный HTTP, а TLS и домен обеспечивает внешний reverse proxy — так бот может
продолжать работать через исходящий прокси (`PROXY_URL`), не открывая входящий доступ
к Telegram.

```
Telegram ──long poll──> бот (через PROXY_URL)
Браузер  ──HTTPS──> Caddy/nginx ──:8080──> Mini App
```

### Настройка

1. Включите сервер в `.env`:

```env
WEBAPP_ENABLED=true
WEBAPP_ADDR=:8080
WEBAPP_PUBLIC_URL=https://dory.example.com
```

2. Настройте reverse proxy. Пример для Caddy:

```caddy
dory.example.com {
    reverse_proxy 127.0.0.1:8080
}
```

Пример для nginx:

```nginx
server {
    server_name dory.example.com;
    listen 443 ssl;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

3. В [@BotFather](https://t.me/BotFather): **Bot Settings → Menu Button** → укажите
   `WEBAPP_PUBLIC_URL`. После этого кнопка меню в личном чате открывает приложение,
   а команда `/app` присылает кнопку запуска.

4. *Для групп.* Кнопки типа `web_app` Telegram разрешает только в личных чатах,
   поэтому из группы приложение открывается ссылкой. Заведите в @BotFather
   **Configure Mini App** с коротким именем `reminders`.

### Локальная отладка

Публичный HTTPS для разработки удобно получить туннелем:

```bash
cloudflared tunnel --url http://localhost:8080
# или: ngrok http 8080
```

Полученный адрес пропишите в `WEBAPP_PUBLIC_URL` и в @BotFather. Quick Tunnel
(`trycloudflare.com`) предназначен только для временной отладки; для постоянной
работы используйте Cloudflare Named Tunnel или собственный reverse proxy.

### Безопасность

- Каждый запрос к API несёт `initData` из Telegram; сервер проверяет HMAC-подпись
  токеном бота и возраст данных (`WEBAPP_INITDATA_TTL`).
- Идентификатор чата в запросе не даёт прав: членство проверяется вызовом
  `getChatMember` к Bot API (с кэшем на 5 минут).
- Чужое напоминание отдаётся как `404`, а не `403`, — чтобы перебором идентификаторов
  нельзя было узнать, какие записи существуют.

## 📊 База данных

Проект использует SQLite. База автоматически создаётся по пути `DB_PATH`
(по умолчанию `data/reminders.db`) при первом запуске.

Схема обновляется версионированными миграциями из `internal/repository/migrate.go`:
применённые версии фиксируются в таблице `schema_migrations`, поэтому существующая
база обновляется без ручных действий.

### Таблицы

- **chats** — чаты (личные и групповые) и их часовые пояса
- **reminders** — напоминания
- **chat_members** — какие пользователи видны боту в каких чатах; нужна, чтобы Mini App
  показал список доступных чатов
- **schema_migrations** — журнал применённых миграций

Подключение открывается в режиме WAL: HTTP-слой Mini App работает с базой параллельно
с планировщиком рассылки.

## 🔧 Конфигурация

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `TELEGRAM_TOKEN` | Токен Telegram-бота | — (обязательно) |
| `BOT_NAME` | Имя бота без `@` | `reminder_bot` |
| `ENV` | Окружение: `dev` или `prod` | `dev` |
| `PROXY_URL` | Исходящий прокси для Bot API (`http`, `https`, `socks5`) | — |
| `DB_PATH` | Путь к файлу базы данных | `data/reminders.db` |
| `WEBAPP_ENABLED` | Включить HTTP-сервер Mini App | `false` |
| `WEBAPP_ADDR` | Адрес прослушивания | `:8080` |
| `WEBAPP_PUBLIC_URL` | Публичный HTTPS-адрес приложения | — (обязательно при `WEBAPP_ENABLED=true`) |
| `WEBAPP_SHORT_NAME` | Короткое имя direct-link Mini App для групп | `reminders` |
| `WEBAPP_INITDATA_TTL` | Максимальный возраст `initData` | `24h` |
